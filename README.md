# Draphos Love

Página inicial responsiva, em português, inspirada no Lovable. O campo de ideias exibe uma prévia no próprio navegador. Esta versão é estática e funciona sem cadastro, instalação ou chave de API.

## Abrir no computador

Extraia o ZIP e abra o arquivo `index.html` no navegador.

## Publicar no GitHub Pages

1. Entre no GitHub e clique em **New repository**.
2. Dê ao repositório o nome `draphos-love` e escolha **Public**. Um repositório público permite que qualquer pessoa veja os arquivos.
3. No repositório, escolha **Add file → Upload files**. Se ele estiver vazio, use o link **uploading an existing file**.
4. Envie `index.html` e `README.md` diretamente para a raiz do repositório. Clique em **Commit changes**.
5. Vá a **Settings → Pages**. Em **Source**, escolha **Deploy from a branch**. Selecione `main` e `/ (root)`, depois clique em **Save**.
6. Aguarde o GitHub publicar e abra o link exibido na tela **Pages**.

Para alterar o site, edite o `index.html` e salve a mudança com um novo commit.
